## Checklist de avaliação — preencher por concorrente

### Logística e disponibilidade

- [ ] Atende no **domingo**? *(sim / não / até que horas)*
- [ ] Tem **plantão fora de horário**? *(sim / não — como funciona?)*
- [ ] Qual o **prazo de entrega**? *(horas / dias de antecedência necessária)*
- [ ] Qual a **área de cobertura** em Franca? *(bairros, raio)*
- [ ] Cobra **frete**? *(sim / não / a partir de qual valor é grátis)*
- [ ] Faz **entrega e instalação** da chopeira? *(sim / não)*
- [ ] Faz **retirada da chopeira** após o evento? *(sim / não / quando)*

### Produto e preços

- [ ] **Marcas disponíveis** *(listar todas)*
- [ ] **Estilos disponíveis** *(Pilsen, IPA, Weiss, etc.)*
- [ ] **Preço barril 30L** *(com chopeira / sem chopeira)*
- [ ] **Preço barril 50L** *(com chopeira / sem chopeira)*
- [ ] **Taxa de locação de chopeira** *(se cobrada separado)*
- [ ] **Mínimo de compra** *(litros ou valor)*
- [ ] Cobra para **barril adicional** durante o evento? *(preço)*
- [ ] Tem **consignação**? *(deixa barril e cobra depois do que foi consumido)*

### Qualidade do atendimento

- [ ] **Tempo de resposta** no primeiro contato *(minutos / horas)*
- [ ] **Qualidade da resposta** *(completa e clara / vaga / sem resposta)*
- [ ] O atendente **fez perguntas** para entender o evento? *(sim / não)*
- [ ] **Tom da abordagem** *(consultivo / vendedor / indiferente)*
- [ ] Ofereceu **alternativas ou recomendações** espontaneamente? *(sim / não)*
- [ ] Enviou **cardápio ou tabela de preços** sem ser pedido? *(sim / não)*

### Argumento de venda

- [ ] Qual é o **principal diferencial** que comunicaram? *(preço / qualidade / serviço / marca)*
- [ ] Falaram sobre **qualidade do produto**? *(sim / não — o que disseram)*
- [ ] Falaram sobre **suporte técnico / instalação**? *(sim / não)*
- [ ] Algum **incentivo de fechamento**? *(desconto, brinde, promoção)*
- [ ] Fizeram **follow-up** após o contato? *(sim / não — em quanto tempo)*
